SEARCH measures × Wikipedia style × TASK correlations · N=130

1הקונטקסט

הניתוח בודק האם סגנון החיפוש של המשתתפים במסע ה-Wikipedia (Hunter / Busybody, ובגרסת k=3 גם Dancer) מנבא את ההתנהגות שלהם במשחק החיפוש המרחבי. אנחנו מציבים זה ליד זה ארבעה מדדים מהמשחק — שניים שטחיים (מבוססי אירועים בלבד) ושניים עמוקים (תוצרי מסווג ה-GBM מ-M81) — ובוחנים שלוש שאלות:

  • (א) האם המדדים העמוקים נותנים יותר אינפורמציה מהשטחיים
  • (ב) האם האפקט של תנאי ה-Clumpy/Diffuse שונה בין הקבוצות
  • (ג) אילו מדדי SEARCH מתואמים לאילו מדדי TASK

2נתונים

  • N = 130 משתתפים (קוהורט M81)
  • סגנון k=2: Hunter: 49, Busybody: 81
  • סגנון k=3: Hunter: 40, Busybody: 41, Dancer: 49
