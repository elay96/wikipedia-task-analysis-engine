## M29: Scree Plot

**מה רואים:** 3 עמודות — כמה שונות (variance) כל מימד מסביר.

**איך קוראים:**
- PC1 = 55.7% — המימד הראשי, מסביר יותר מחצי מהשונות
- PC2 = 33.3% — מימד שני משמעותי
- PC3 = 11.0% — שארית

**מסקנה:** Explore/Exploit **לא חד-ממדי**. אם היה מימד אחד, PC1 היה מסביר >80%. במקום זה יש **שני מימדים משמעותיים** שמסבירים יחד 89%.

## M30: Biplot — מרחב ההתנהגות

**מה רואים:** כל נקודה = ביקור בדף אחד. צבע = דומיין (ורוד = art_history, ירוק = ecology, סגול = psychology, כתום = economics). חצים כתומים = כיוון המשתנים המקוריים.

**הצירים:**
- **ציר X (PC1 — Engagement, 55.7%):** ימינה = זמן ארוך + כתיבה רבה. שמאלה = גלישה מהירה ללא כתיבה.
- **ציר Y (PC2 — Semantic Breadth, 33.3%):** למעלה = קפיצה לנושא שונה. למטה = אותו נושא.

**הרבעים:**
| | שמאל (engagement נמוך) | ימין (engagement גבוה) |
|---|---|---|
| **למעלה** (נושא שונה) | גלישה מהירה + נושא חדש = **EXPLORATION** | קריאה עמוקה + נושא חדש |
| **למטה** (נושא דומה) | גלישה מהירה + אותו נושא | קריאה עמוקה + כתיבה + אותו נושא = **EXPLOITATION** |

**איך קוראים את החצים:**
- "Time on page" ו-"Writing amount" מצביעים לאותו כיוון (ימינה) — הם מתואמים. מי שמבלה זמן רב גם כותב הרבה.
- "Topic distance" מצביע למעלה, **בניצב** לשני האחרים — הציר הסמנטי **בלתי תלוי** מציר המעורבות.

**מסקנות:**
1. אפשר לבלות זמן רב בדף (exploit מבחינת engagement) אבל עדיין לקפוץ בין נושאים רחוקים (explore מבחינה סמנטית) — ולהפך.
2. יש פיזור שונה בין דומיינים — economics (כתום) נוטה להתרכז, ecology (ירוק) מפוזר יותר.

## M31: מפת נבדקים — אסטרטגיות אינדיבידואליות

**מה רואים:** כל **נבדק** = נקודה אחת (ממוצע כל הביקורים שלו) + אליפסה (סטיית תקן). אותם צירים כמו M30.

**איך קוראים:**
- **מיקום הנקודה** = האסטרטגיה הדומיננטית של הנבדק
- **גודל האליפסה** = כמה הנבדק עקבי
  - אליפסה קטנה = אסטרטגיה יציבה (תמיד באותו רבע)
  - אליפסה גדולה = מחליף אסטרטגיות (קופץ בין רבעים)

**מסקנות:**
1. **הבדלים אינדיבידואליים ברורים** — הנבדקים לא מקובצים באותו מקום, כל אחד עם אסטרטגיה שונה.
2. **רוב הנבדקים** נמצאים באזור שמאל-מרכז (engagement בינוני-נמוך) עם פיזור ב-Y (חלקם חוקרים נושאים שונים, חלקם נשארים בנושא).
3. **נבדקים עם אליפסות צרות** — אסטרטגיה עקבית, אולי "יודעים מה הם רוצים".
4. **נבדקים עם אליפסות רחבות** — מחליפים בין explore ו-exploit, אולי מתאימים אסטרטגיה למשימה.

## M32: Composite — תרשים מסכם

**מה רואים:** שלושת הפאנלים יחד:

| פאנל | מה מראה | המסקנה המרכזית |
|------|---------|----------------|
| **A. Variance Explained** | Scree plot | שני מימדים, לא אחד |
| **B. Behavioral Space** | Biplot עם דומיינים | הצירים: engagement vs. semantic breadth |
| **C. Individual Strategies** | מפת נבדקים | כל נבדק עם אסטרטגיה אחרת |

**הסיפור בשלוש משפטים:**
1. Explore/Exploit בויקיפדיה הוא לא מימד יחיד — יש ציר מעורבות (זמן + כתיבה) וציר חקירה סמנטית (מרחק נושאי), והם חלקית בלתי תלויים.
2. אפשר להיות "exploiter" מבחינת engagement אבל "explorer" מבחינה סמנטית — לכתוב הרבה תוך כדי קפיצה בין נושאים.
3. יש הבדלים אינדיבידואליים משמעותיים — כל נבדק עם תמהיל שונה של שני הצירים.
