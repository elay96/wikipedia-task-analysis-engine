M30 Biplot — מרחב ההתנהגות

מה רואים

כל נקודה = ביקור בדף אחד. צבע = דומיין: ורוד = art_history, ירוק = ecology, סגול = psychology, כתום = economics. חצים כתומים = כיוון המשתנים המקוריים.

הצירים

  • PC1 — Engagement ,ציר X, מסביר 55.7%: ימינה = זמן ארוך + כתיבה רבה. שמאלה = גלישה מהירה ללא כתיבה.
  • PC2 — Semantic Breadth ,ציר Y, מסביר 33.3%: למעלה = קפיצה לנושא שונה. למטה = אותו נושא.

הרבעים

שמאל (engagement נמוך) ימין (engagement גבוה)
למעלה (נושא שונה) גלישה מהירה + נושא חדש = EXPLORATION קריאה עמוקה + נושא חדש
למטה (נושא דומה) גלישה מהירה + אותו נושא קריאה עמוקה + כתיבה + אותו נושא = EXPLOITATION

איך קוראים את החצים

  • החצים Time on page ו-Writing amount מצביעים לאותו כיוון (ימינה) — הם מתואמים. מי שמבלה זמן רב גם כותב הרבה.
  • החץ Topic distance מצביע למעלה, בניצב לשני האחרים — הציר הסמנטי בלתי תלוי מציר המעורבות.

מסקנות

  1. אפשר לבלות זמן רב בדף (exploit מבחינת engagement) אבל עדיין לקפוץ בין נושאים רחוקים (explore מבחינה סמנטית) — ולהפך.
  2. יש פיזור שונה בין דומיינים — economics (כתום) נוטה להתרכז, ecology (ירוק) מפוזר יותר.

M31 מפת נבדקים — אסטרטגיות אינדיבידואליות

מה רואים

כל נבדק = נקודה אחת (ממוצע כל הביקורים שלו) + אליפסה (סטיית תקן). אותם צירים כמו M30.

איך קוראים

אלמנט מה הוא מייצג
מיקום הנקודה האסטרטגיה הדומיננטית של הנבדק
גודל האליפסה כמה הנבדק עקבי
אליפסה קטנה אסטרטגיה יציבה — תמיד באותו רבע
אליפסה גדולה מחליף אסטרטגיות — קופץ בין רבעים

מסקנות

  1. הבדלים אינדיבידואליים ברורים — הנבדקים לא מקובצים באותו מקום, כל אחד עם אסטרטגיה שונה.
  2. רוב הנבדקים נמצאים באזור שמאל-מרכז, עם רמת engagement בינונית-נמוכה. חלקם חוקרים נושאים שונים וחלקם נשארים בנושא.
  3. נבדקים עם אליפסות צרות — אסטרטגיה עקבית, אולי "יודעים מה הם רוצים".
  4. נבדקים עם אליפסות רחבות — מחליפים בין explore ו-exploit, אולי מתאימים אסטרטגיה למשימה.
